what's a noop?

Every CPU has an instruction called NOP, "no operation." It does nothing for one cycle, on purpose. It exists to pad, to wait, to hold a spot.

Solana ships a program literally named No-op. Send it a transaction with data attached and it does nothing except leave that data in the permanent ledger. That's how this whole site got on chain.

So: the CPU instruction that does nothing, stored by the program that does nothing, as the coin that does nothing. Three noops. One joke. Forever.

You are a NOOP instruction inside a CPU. Every other instruction is trying to do something. Halt them. Four levels. The last one is called RUG.

how this page loads

  1. A 2 KB loader on noopcoin.fun asks a Solana RPC node for the root transaction.
  2. The root lists the index transactions. The indexes list every data chunk, in order.
  3. Your browser fetches the chunks, concatenates them, gunzips the result.
  4. It hashes the bytes and compares them to the SHA-256 in the root. Match, and the page you're reading replaces the loader.
